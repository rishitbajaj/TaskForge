# ⚡ TaskForge: AI-Powered Productivity

TaskForge is a full-stack MERN (MongoDB, Express, React, Node.js) application designed with a futuristic "Cyber-Grid" UI.

## 🚀 Getting Started

### 1. Clone the repository
git clone https://github.com/[YOUR_USERNAME]/TaskForge.git
cd TaskForge

### 2. Setup Backend
1. `cd backend`
2. `npm install`
3. Create a `.env` file based on `.env.example` and add your MongoDB URI.
4. `npm run dev` (Starts server on port 5000)

### 3. Setup Frontend
1. `cd ../frontend`
2. `npm install`
3. `npm start` (Starts React on port 3000)

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS/Framer Motion
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Tokens)
